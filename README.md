# AOE1 Android

Native Android foundation for a clean-room Age of Empires 1-compatible RTS engine. This repository does not include proprietary game code or assets. Players provide legally obtained game data themselves.

## Status

`v0.1.0-foundation` is under development. The initial milestone targets an SDL2 + OpenGL ES Android shell, touch camera controls, ARM64 APK builds, and CI.
